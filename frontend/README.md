# User Search App

A simple React application that fetches and displays a list of users from an API, with a search functionality to filter users by name.

## Features
- Fetches user data from `https://jsonplaceholder.typicode.com/users`
- Displays a list of users with their names and email addresses
- Provides a search bar to filter users by name
- Shows a loading message while fetching data

## Technologies Used
- React.js
- Axios (for API requests)
- CSS (for basic styling)
